# WAV変換の文字保持確認用BASIC

UTF-8、BOMなしの独自サンプル。実機での実行・画面表示ではなく、BASIC→WAV→BASICの変換確認用。

| ファイル | WAVエンコード形式 | 確認内容 |
| --- | --- | --- |
| [KANA_S1.bas](KANA_S1.bas) | S1・BASICパスワードなし | 半角カナ、濁点・半濁点、小書き、長音、句読点 |
| [TEXT_S2.bas](TEXT_S2.bas) | S2・BASICパスワードなし | 漢字、全角／半角カナ、濁点・半濁点、小書き、長音、混在文字列 |

PRINTの文字列、REMのコメント、REM内のダブルクォート、PRINTとREMを含む同一行を用意した。
引用符内・REM内の`PRINT REM GOTO`が命令へ変換されず、文字列として保持されることを確認する。
最後のREM行は意図的にダブルクォートを閉じていない。REM以降では引用符も単なるコメント文字として扱う確認用。

転送名は`KANA_S1`／`TEXT_S2`。生成WAVを自動Decodeし、文字列とコメントの文字・空白を確認する。
行番号と命令は変換後に整形される場合があるため、厳密な確認は再コンパイルしたBASIC imageのbyteを比較する。
