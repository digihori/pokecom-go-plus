# PC-1350 Coffee Break

パックマン風のオリジナル図形によるコーヒーブレイク風デモです。
1. 通常サイズのキャラクターがゴーストに追われ、左へ逃げる。
2. 大きなキャラクターが反転し、右へ逃げるゴーストを追いかける。
3. コーヒーカップと「BACK TO BASIC」を表示して終了する。

口とゴーストの足を2パターンでアニメーションします。追跡中の2音の効果音と、開始・コーヒー休憩時の短いオリジナル旋律を付けています。
ポートCのbit 4をソフトウェアで切り替え、終了時には元のポート設定へ戻します。
ROMや元のゲームの画像・コードは含めず、ROMの描画ルーチンも呼びません。

## 実行

Studio内蔵AssemblerでBuild／Loadし、RUNモードで`RUN`を実行してください。
Assemblyだけをロードした場合は、BASICから`CALL 24576`（開始`0x6000`）で起動します。
標準速度で約23秒、1回再生してBASICへ戻ります。アニメーション中のキー入力は処理しません。

コード／画像データ用として`0x5000..0x6895`を確保し、この範囲に既存プログラムや変数を置かないでください。
BASICの管理ポインター`0x6F01..0x6F04`、LCDの記号`0x783C`、キー選択`0x7E00`は変更しません。
I/J・X/Y・内部レジスター8/9/10・ポートCを保存し、A/P/Q/DP・フラグを変更します。CALLから起動してください。

表示の配置はPGPの`Pc1350Display`／`FourLineDisplay`を基準にしています。
PGPでの動作検証であり、実機や任意のROMでの動作保証ではありません。
`expected-art.json`は自動テスト用の独自画像データで、実行時に別途読み込む必要はありません。
