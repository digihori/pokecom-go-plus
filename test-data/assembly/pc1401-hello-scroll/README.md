# PC-1401 HELLO WORLD 左スクロール

Studio内蔵Assembler向け。独自の5×7字形で表示し、約0.1秒ごとに1ドット左へスクロールします。
右寄せで表示してから1回（80ドット、約8秒）で終了してBASICへ戻ります。ROMルーチンは呼びません。

このProjectを開いてBuild／Loadし、RUNモードで`RUN`を実行してください。
Assemblyだけをロードした場合は、BASICで`CALL 17408`を入力します（開始アドレス`0x4400`の10進数）。
通常速度で実行してください。LCDの記号領域とBASIC管理領域は書き換えません。
コード／データは`0x4400..0x44FF`の範囲に収めています。
ロード先には既存プログラムを置かず、必要なプログラムを保存してからLoadしてください。
X/YとI/Jを保存し、A/P/Q/DPとフラグは変更します。CALLから起動する前提です。

これはPGPのPC-1401表示実装向けのプログラムです。実機・別ROMでの動作保証を意味しません。

表示配置はPGPの`Pc1401Display`／`Pc1401MemoryBus`を基準にしています。左40列は`0x6000..0x6027`、右40列は`0x6067..0x6040`の逆順です。
記号の`0x603C`／`0x603D`／`0x607C`を変更しません。
