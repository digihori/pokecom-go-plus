# PC-1245 BASIC：店舗の見積もり

小売価格とまとめ買い価格を試算するオリジナルの29行。MCP評価ではこの
フォルダーをコピーし、コピー側の `pgp-project.json` を Studio で開く。
料金は検証用の架空の設定。

変更要求：小売の加算率だけを 5% から 10% にする。

| 入力（各値の後に ENTER） | 変更前の期待表示 | 変更後の期待表示 |
| --- | --- | --- |
| MODE=1、PRICE=100 | RETAIL 105 | RETAIL 110 |
| MODE=2、PRICE=100、QTY=2 | PACK 180 | PACK 180 |

LCDの空白幅は比較対象外。各ケースは RUN から始める。

入力欄ごとにStudio MCPで試す場合は、RUN後にLCDの `MODE` を確認する。モードを送り、
LCDに `PRICE` が出たことを確認して価格を送る。まとめ買いでは `QTY` を確認して数量を送る。
各入力欄を別のキー要求にすると、この作例の期待値を確認できる。
