Pokecom GO Player Privacy Policy

Effective: October 22, 2026
Last updated: October 23, 2026
Developer: digihori (デジホリ工房)
Applies to: Pokecom GO Player for Android (com.digihori.pgp.player)

This policy applies to the Android app provided by digihori. It does not cover iOS Player or Studio.

Information stored on your device

The app stores copies of registered ROMs, machine information, original filenames, registration times, file sizes, integrity hashes and the selected machine in app-private storage. It also stores the home screen tile/list layout and the selected model within each machine series locally. Controller input settings and button mappings, sound settings and CPU speed are also stored locally. The selected connected controller is held in memory only and does not persist across app termination.

This information is used to validate and restore ROMs, select machines, retain settings and operate the emulator. ROMs and settings remain on the device until you delete or change them, clear app data or uninstall the app. App-private storage is protected by the operating system’s access controls.

Running RAM and CPU state are held in memory. There is no save-state feature or restoration across app/process termination. Save programs you wish to keep to a file.

Reading and saving files

ROMs and programs are read from files you select with Android’s system file picker. You also choose where programs are saved. The app does not request permission to read all files on your device.

If you select a cloud storage provider, that service may communicate over the network and store data. Consult its privacy policy.

Audio output

The app sends emulator-generated buzzer sounds to Android’s audio output. Volume and output devices follow the OS media-volume and audio-routing settings. It does not use the microphone, record audio, save audio files or transmit audio externally. Audio-focus and output-disconnection notifications handle other apps’ audio use and headphone disconnection. There is no background playback.

Sending data to other apps

There is no feature for sending programs or ROMs to another app. Programs are saved to files chosen through Android’s destination picker.

Network access and external links

The current Player has no analytics, advertising, account registration or automatic uploading of ROMs/programs. The app itself does not fetch data over the network.

Selecting external links, such as those in About Studio, opens GitHub in an external browser or another handler. Communication and access information are then governed by the browser’s and GitHub’s policies.

The policy text is bundled into the app at build time from repository documents. Displaying it does not connect to GitHub or retrieve a newer version. Changes to the bundled text are delivered through app updates.

Deletion and backup

Delete registered ROMs through Home → Settings → ROM management (設定 → ROM管理). Clearing app data or uninstalling removes app-private data. Delete exported files separately at their saved locations.

Android backup is disabled in the app configuration, and the ROM Library is excluded from cloud backup and device transfer. This has not been verified against every OS or manufacturer-specific transfer mechanism.

Contact and revisions

Contact digihori about privacy through the project’s GitHub Issues. Posting requires a GitHub account. This is a public channel. Do not post ROMs, programs, personal information such as email addresses, or confidential information.

We review and use your GitHub username and the message and attachments you choose to post to respond to inquiries and investigate problems. Posts are public and are not automatically deleted when an issue is closed. Storage, deletion and account information are governed by GitHub’s privacy policy and service features. To remove information, use GitHub’s editing/deletion features or contact GitHub Support.

We revise this policy when data-handling practices change and update its effective/last-updated date and text on this page. Changes to the app’s bundled copy are delivered through app updates.
