English

Android Player はじめに

ROMの準備から、スマートフォンでポケコンを起動するまでのガイドです。Playerは操作・実行用、StudioはPCでのプログラム開発とROMパッケージ作成用です。

ROMは同梱していません。 ご自身で適法に入手した対象機種のROMが必要です。アプリをインストールするだけではポケコンは起動しません。このガイドはROMの配布や入手サイトを案内するものではありません。

1. 準備 → 2. ROM形式 → 3. Studioで作成 → 4. 転送 → 5. 登録・起動 → 困ったとき

1. 用意するもの

  • Android 8.0以降の端末とPokecom GO Player。配布版の対応条件も確認してください。
  • 使用する機種のROMファイル、または作成済みの .pgrom。
  • ROMをパッケージ化する場合は、macOS／Windows／LinuxのPCとPokecom GO Studio。

ROMがすでに .pgrom なら、転送手順へ進めます。対応する従来形式のROMも、Studioなしで直接登録できます。

2. 機種に合うROM形式を選ぶ

.pgrom は機種情報・ROMデータ・整合性確認情報をまとめたパッケージです。拡張子を変更するだけでは作れません。ROMはBASICプログラム（.bas）やメモリダンプ（.dmp）とは別です。

対象機種直接登録できる従来形式別々のROMダンプがある場合
PC-1245／1250／1251／125532または64 KiBの対応フラットイメージStudioで .pgrom を作成
PC-1260／1261／1350／1401／1402／145064 KiBの対応フラットイメージStudioで .pgrom を作成
PC-1360／1360K／1460／1470U単一フラットイメージは非対応Studioで .pgrom を作成して登録

サイズが同じでも任意のROMを使えるわけではありません。従来のPokecom GOに対応するメモリ配置が必要です。機種は自動判定しないため、正しい機種を選んで登録してください。

3. Studioで .pgrom を作成する

Studioをダウンロード

利用するOS向けの配布物を選び、リリースノートの対応機種と制限を確認してください。開発中のソースと公開済み配布版では機能が異なる場合があります。対象機種が作成画面にない場合は、その機種に対応する配布版が必要です。

  1. Studioを起動し、ファイル → ROMセットを作成（File → Create ROM Set…）を開きます。
  2. 機種 / Machineで対象機種を選びます。
  3. 内部ROM / Internal ROMと外部ROM / External ROMに、それぞれのダンプファイルを指定します。従来形式の32／64 KiBファイルをそのまま内部ROM欄へ入れないでください。
  4. PC-1360Kで漢字機能を使う場合は、後述の漢字ROMも指定します。
  5. 保存先と名前（例: pc1245.pgrom）を指定し、作成 / Createを押します。
  6. 成功表示を確認します。ROM Libraryに登録 / Register in ROM LibraryはStudioで使うための追加操作で、Player用ファイルを作るだけなら不要です。

分割ダンプから作成するときのサイズ

機種内部ROM外部ROM
PC-1245／1250／1251／12558 KiB16 KiB
PC-1260／1261／1350／1401／1402／14508 KiB32 KiB
PC-14608 KiB64 KiB（16 KiB × 4バンク）
PC-1360／1360K／1470U8 KiB128 KiB（16 KiB × 8バンク）

1 KiB = 1024バイトです。バンクROMはbank 0から番号順に連結済みの外部ROMファイルが必要です。作成画面には個別バンクを選んで連結する機能はありません。順序が不明なファイルを推測で連結しないでください。

PC-1360Kの漢字ROMはselectorごとに64 KiBです。かな漢字変換にはselector 0〜3の4ファイルを用意します。漢字ROMのない構成では漢字機能に制限があります。ROM抽出自体の手順はこのガイドの対象外です。

4. Androidへファイルを転送する

  1. 作成した .pgrom、または対応する従来形式ROMをUSBなどでAndroidへコピーします。USB接続時は端末側でファイル転送を許可してください。
  2. 例として端末の Download フォルダーへ保存します。クラウドドライブを使う場合はAndroidのファイル選択画面から開ける状態にします。
  3. クラウド上だけにあるファイルはダウンロード完了を待ちます。ファイル名や拡張子を変更せず、PCにも元ファイルを保管してください。

StudioとPlayerの間で自動同期は行いません。クラウドの通信・保存は利用したサービスの方針に従います。

5. Playerで登録して起動する

  1. Playerのホームで使う機種を探します。同じシリーズのモデルは機種名のプルダウンから選びます。
  2. その機種のROMを登録を押し、Androidのファイル選択画面で転送したファイルを選びます。
  3. 登録が成功したらプレイを押します。初回のプレイ入場でCPUが動き始めます。
  4. 画面キーで操作します。BASICを使うときは機種に応じてRUN／PROやCAL／BASICを切り替えます。

PC-1250／1251／1255、PC-1260／1261、PC-1401／1402ではシリーズ内でROMを共有します。別シリーズのROMは使えません。PC-1401／1402の容量認識はROM版にも依存します。

6. プログラムを使い、保存する

機種画面のメニューでプログラム → ロードを選ぶと、機種に合ったUTF-8のBASICテキスト（.bas）やPGP Memory Dump（.dmp）を読み込めます。ロード後のCPU実行と、BASICの RUN コマンドは別です。BASICは必要に応じてポケコン側で RUN を実行してください。

終了前に保存してください。 プログラム → セーブでBASICをファイルに保存できます。RAMや実行状態はアプリ終了後に復元しません。DMPはロード専用で、Playerからは保存できません。ROMの置換や機種切替でも現在のRAMを失います。

StudioのProject、Assembler、Debugger、WAV入出力はPlayerにはありません。Studioから渡す場合は対応する .bas または .dmp を使います。

困ったとき

  • ファイルが見つからない：ファイル選択画面でDownloadや保存元を開き、クラウドの取得完了と拡張子を確認します。
  • ROMのサイズ・機種・整合性エラー：選択機種、入力ファイル、バンク順序を確認し、必要ならStudioで作り直します。.pgromの内部を書き換えたり拡張子だけ変更したりしないでください。
  • 作成ボタンが押せない：内部／外部ROMのサイズ、保存先、漢字ROMの組み合わせと各欄のエラーを確認します。
  • 起動しない・キーが効かない：CPUが停止中でないか、機種とROM版が合っているかを確認します。背景から戻ると通常は停止状態です。Resetは現在のプログラムを失う可能性があるため、保存後に行ってください。
  • 音が出ない：Playerのサウンド設定、端末のメディア音量、Bluetoothなどの出力先を確認します。
  • 解決しない：GitHub Issuesへ、Player／Studioの版、端末・Android版、機種、エラー文、再現手順を添えてください。ROMや個人情報は添付しないでください。公開の窓口です。
