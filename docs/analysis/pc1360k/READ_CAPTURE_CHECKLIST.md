# PC-1360K 4KiB取得一覧

> この文書は個別実験の経過記録です。「未取得」「未実装」等は各記述時点の状態を示します。
> 現在のまとめは[PC-1360K 漢字ROM解析とStudio対応](../../reference/machines/PC-1360K.md)、
> 吸い出し用BASICの使い方は[配布用手順書](../../../tools/pc1360k-rom-dump/README.md)を参照してください。

2026-10-18。selector 0/1と16ビットDPで指定する論理範囲の取得一覧。
全容量・物理的なS/T対応は未確定。32ブロックを取得する計画であり、
128KiBすべてが独立した物理ROMであると確定したものではない。

[プログラムと操作手順](READ_FAST_4K.md)。各回、行60のS/Aを変更してRUNし、
SUM・Dを記録して表示を最後まで進め、`CSAVE M 53248,57343`で保存する。
デコード後のペイロードは毎回4096バイト。前のファイルを上書きしない。
Dが0でない場合は異常として記録し、正常な取得データと混ぜない。

取得済み32/32ブロック（128KiB）。全件を一括録音から抽出・検証済み。
selectorごとに64KiBへ結合し、以前の個別取得とも照合済み。
ファイル合計と実機SUMを確認し、既知値・重複範囲があれば全バイト照合する。
ROM由来ファイルと由来情報はlocal-data以下にのみ保存する。
