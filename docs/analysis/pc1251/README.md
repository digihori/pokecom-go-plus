# PC-1251実機でのLDPC／MVMP比較

PC-1360Kの[実機比較](../pc1360k/PC-1360K_HISTORY.md)では、両命令の読出し値が
DPと漢字ROM選択値に依存した。PC-1251でもデータ取得がDPに依存するかを、次の命令の
先頭バイトとDPを独立に変えて調べる。PC-1251実機の結果は未取得。

## 実行

1. PC-1251の必要なBASICプログラムやメモリ内容を退避する。
   試験は短い専用BASICだけをロードした状態で行い、`0xC500〜0xC582` と
   `0xC590〜0xC599` が常駐コード等に使われていないことを確認する。
2. [BASICローダー](ldpc-mvmp-probe.bas)を入力するか、OLD BASICのWAVとして転送する。
   リポジトリ直下からの生成例：

   ```sh
   perl tools/pcwav/pcwav-encode.pl oldbasic docs/analysis/pc1251/ldpc-mvmp-probe.bas probe.wav RDPROBE
   ```

3. RUNモードで `RUN`。ローダーが131バイトをPOKEし、`CALL 50432` で
   `0xC500` のプローブを呼ぶ。正常時は結果を表示せずBASICへ戻る。
4. 下記の各番地を通常のBASICのPEEKで読み、機種名と値を記録する。
   例：`PRINT PEEK(50578)`。A/Bは同じ命令の別の実行位置を指す。

| 項目 | 結果番地（10進） | 命令直後のバイトを読む場合（10進） | 通常RAMのDP先を読む場合（10進） |
| --- | --- | --- | --- |
| RAM確認値 | 50576, 50577 | 165, 90 | 165, 90 |
| LDPC A | 50578, 50579 | 3, 3 | 165, 90 |
| LDPC B | 50580, 50581 | 18, 18 | 165, 90 |
| MVMP A | 50582, 50583 | 89, 89 | 165, 90 |
| MVMP B | 50584, 50585 | 18, 18 | 165, 90 |

各組は DP=`0xC590`、`0xC591` の順。RAM確認値が違えば、まずロード・実行条件を確認する。
両予測と異なる場合も、そのまま記録する。後続バイトと同じ値が得られても、外部バスに
DPが一切現れないことまでは示さない。DP依存が見えても、その結果だけで1360KのA16/A17の
配線やゲートアレイの動作を確定できない。

[アセンブリ](ldpc-mvmp-probe.asm)はI/O出力・バンク選択レジスタへの書込みを行わず、
A/B/Pと内部RAM `0x20` を復元する。DP・演算フラグは保存しない。

PGPでは、ローカルのPC-1251 ROMでBASICを入力し、RUNによるDATA→POKE、CALL、RTN後の
結果を確認した。131バイトのロード内容はアセンブル結果と一致し、結果は
`165,90 / 3,3 / 18,18 / 89,89 / 18,18`。これはエミュレータの比較基準であり、
PC-1251実機の測定結果ではない。
