# Debugger強化：操作性・文書・環境別受入れ

確認日：2026-10-30。`codex/debugger-enhancements`の作業8です。
自動検証・隔離描画・配布runtime生成と、配布アプリ・実ROMの手動受入れを区別します。
作業1〜7の機能実装と今回の自動確認は済んでいますが、全OS・全機種の受入れ完了ではありません。

## 今回の改善

- メモリ側の先頭をMemory Viewにし、検索結果から移動した際に値がすぐ見える配置にしました。
- 位置移動時に入力フォーカスを解放してからスクロールを戻します。
  入力欄への自動スクロールと位置移動が競合せず、エミュレータ入力の所有権も戻ります。
- ROM bank欄の長いラベルを短くし、10進・空欄の意味は説明文に残しました。
- [英語操作ガイド](../guides/DEBUGGER.en.md)を追加し、英語README・目次から案内します。

## ローカルで確認した範囲

環境：macOS 26.6.2、arm64、JDK 21.0.11。合成ROM／Sessionを使い、実Preferences・ROM Library・
MCP認証情報・SDL実入力を使わずに確認しました。

```sh
./gradlew :core:desktopTest :desktopApp:test build :desktopApp:verifyDistributionRuntime --console=plain
git diff --check
```

全体buildとmacOS配布アプリ生成・runtime検証が成功しました。配布runtimeは必要な
`jdk.unsupported`・`jdk.httpserver`を含みます。アプリ生成は署名付き公開・インストール・起動受入れとは区別します。
未変更タスクは増分build結果を再利用しています。

| 対象 | テスト数 | 失敗／エラー | skip |
| --- | ---: | ---: | ---: |
| Core desktopTest | 500 | 0 | 0 |
| Studio test | 467 | 0 | 2 |

skipは既存のローカル実ROMを使うHELLO WORLD試験とSDL仮想ゲームパッド試験です。
この2件の動作成功を示すものではありません。新しい統合試験にskipはありません。

`DebuggerReleaseAcceptanceTest`は日英×幅420／1200、狭幅800／広幅900の高さで以下を確認します。

- 検索欄へfocusして実際に表示領域へスクロールし、入力中のエミュレータキー転送を拒否する。
- 検索結果が見える位置までスクロールし、結果を選択してMemory Viewの先頭行へ戻る。
  上部の実行操作が動かず、テキストfocusと入力ブロックが解放される。
- 登録・履歴・メモリ間のタブ切替でfocusを解放し、メモリ検索の入力値を保持する。
- bank指定の表示、ログポイント入力、履歴出力の件数入力と保存要求を共通レイアウトで扱う。
- これらの画面操作でCPU・RAM・Session revisionを変えない。

生成画像は`desktopApp/build/reports/debugger-release/`の
`{english,japanese}-{420,1200}-{memory,search,registrations,logpoints,history}.png`です。
20枚を生成し、代表的な日本語狭幅のメモリ・検索・ログ・履歴と英語広幅の登録等を目視確認しました。
スクロールによる画面外の内容と、文字の欠落・レイアウト崩れを区別しています。
ネイティブマウス・Tab／Enter／IMEを通した配布アプリの操作確認とは別です。
