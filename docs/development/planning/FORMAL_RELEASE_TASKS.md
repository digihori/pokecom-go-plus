## 既知問題の対応方針（2026-10-23確定）

- 正式版に向けて対応する既知問題は、PC-1245／1250／1251／1255系のメモリ容量とミラー処理に絞ります。
  1260／1261も含む[RAM仕様一覧](../../reference/machines/RAM_1245_1261.md)を基準とし、1260／1261は既存処理との一致を確認します。
  2026-10-25追加：AI連携のHTTP入口強化（M10）は、この従来方針に追加する次回リリース必須のセキュリティ対応です。
- MEM表示が意図した値にならない件はペンディングとし、正式版のMUSTから外します。2026-10-23時点で、確認した全てのROMで9630になる結果を記録しました。機種・RAMモード等の条件の切り分けは再開時に行います。
- StudioとAndroidのサウンドは現状で問題ない水準とし、改善タスクを追加しません。iOSのサウンド改善は別スレッドで進めます。
- PC-1402のROM照合、PC-1470UのSHIFT TITLE、Step Over／Outの未対応経路など、その他の既知制限は今回の修正対象に含めず、制限の案内を維持します。
