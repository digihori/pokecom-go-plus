## 旧URLと見出しの維持

公開済みMarkdownの旧パス97件は、本文の複製ではなく新パスへの案内に置き換えました。
旧配布版のヘルプや既存のブックマークを維持するためです。以前の見出しも残し、
手順3で履歴へ分離した小見出しは、その履歴の節へ案内します。

新規の文書・アプリ・ビルド参照は分類後の本文を指します。旧パスの案内を本文として編集しないでください。
