# Android Player プログラムのロード・保存

PC-1245 Android Playerの3点メニューから操作する。対応形式はUTF-8 BASICテキスト
`.bas`とアドレス付きPGP Memory Dump `.dmp`。bin、hex、WAV、Projectは対象外。

## ロード

1. 「プログラム」→「ロード」でCPUを一時停止し、Androidのファイル選択画面を開く。
2. ファイル名の拡張子からbas／dmpを自動判定し、内容を検証する。
3. 検証成功後は上書き確認を挟まず直接ロードする。
4. BASICはプログラム全体を置換する。dmpは記載アドレスのRAMを上書きする。
   C000やBASIC管理ポインタへの書込みも許可するため、BASICが壊れる場合がある。
5. BASICロード後はPAUSED。dmpロード成功後はROMのCPU実行を自動再開する。BASICプログラムを実行するには、
   ポケコン側のRUNコマンドを使用する。ロードがRUNを自動入力することはない。

ファイルは2 MiBまで。bas／dmp以外の拡張子、不正なUTF-8／書式、容量超過、
ROM／LCD／制御領域への書込み、ミラー重複は拒否する。
BASICロード・保存は有効なBASIC管理領域を必要とするが、dmpロードはBASICの状態に依存しない。
キャンセル・検証失敗ではメモリを変更せず、PAUSEDを維持する。
Resetは「実行操作」から行う。Reset後は動作モードRUN、CPU自動実行（RUNNING）となる。


## 保存・共有

「プログラム」→「保存・共有」でCPUを一時停止し、形式を選ぶ。

- BASIC：現在のプログラム全体をbasへ変換する。
- ダンプ：開始・終了アドレスを16進数で指定する。終了アドレスを含む単一RAM範囲をdmpへ変換する。
- 「ファイルへ保存」：Androidの保存先選択画面で新規ファイルを作成する。
- 「共有」：取得済みデータをアプリの共有用cacheに保存し、Androidの共有シートへ渡す。

既存ファイルへの直接上書きは今回の保存操作に含めない。保存・共有がキャンセル／失敗しても
エミュレータのメモリは変わらない。書込み先でのI/O失敗では、作成したファイルが不完全に
残る場合があるため、保存完了表示を確認する。

共有用URIは読取り権限だけを付与し、共有専用cache領域に限定する。各共有ファイルは別の
ディレクトリへ保存するため、後の共有で前の内容を上書きしない。共有・保存後もPAUSED。
通常の画面反転では操作状態を保持するが、プロセス終了後に未完了の操作は復元しない。

## 端末確認項目

- ファイルpickerでキャンセル／選択、拡張子自動判定、保存したbasの再ロード
- C000を含む非連続dmpの直接ロード、指定範囲の保存と再ロード
- bin／hex選択、不正UTF-8、容量超過、保護領域への書込みでエラー表示
- 保存先pickerのキャンセル、共有シートの受取り側で内容確認
- 両横向きで確認・保存ダイアログ、アドレス入力時のキーボード、ノッチ回避
- 操作中の背景移行・復帰、キー解放、ゲームパッド入力の抑止

## メニューとLCD表示

メニューは同じ画面内の階層パネル（実行操作／プログラム／動作モード／表示／機種・ROM／情報／コントローラー設定）。
端末の戻る操作は子階層から親へ、親から閉じる。メニュー表示中はゲームパッド入力を抑止する。
LCDのシンボル・動作モード文字は計測して枠内に収め、端末の文字サイズ設定で欠けない描画にする。
メニュー・ダイアログは通常の文字サイズ設定に追従する。
端末では文字サイズを変えて通常／拡大表示、メニュータップ時のステータスバー、Reset後の自動実行を確認する。

## 機種・ROM

- 「機種・ROM」で保存済みROM一覧を開く。現在はPC-1245のみ選択可能。
  Coreだけが対応している機種は表示しない。PC-1401／1350はスキン対応時に追加する。
- 未登録なら「取込み」、登録済みなら「置換」。pgromまたはPC-1245 legacy ROMを選択する。
- 取込みは検証・新Session生成の後に保存する。既存ROMの置換または使用中Sessionを変更する場合は、
  RAM／ロード済みプログラムが失われることを確認してから確定する。
- 「使用する」は保存済みROMから新Sessionを生成して切り替える。現在使用中の機種には無効。
- 「削除」は確認後に保存ROMを削除する。使用中ならSessionも破棄し、ROM未登録画面へ戻る。
  別機種へ自動で切り替えることはない。
- ROM管理を開くと一時停止し、キャンセル・失敗時は既存SessionとRAMを保持する。
  検証失敗時は保存済みROMを変更しない。保存途中で失敗した場合は変更済みファイルの復元を試みる。
- 成功した取込み／置換／機種切替はRUNモード・CPU自動実行。通常／拡大の表示選択は維持する。
  未実行の自動開始は、背景に移った場合は画面復帰まで待機する。

## 情報

「情報」にはインストール済みアプリのバージョン名／番号、プライバシーポリシー、Studio案内を置く。
後二つはユーザー指定の仮文言をアプリ内に表示し、外部URLは開かない。
