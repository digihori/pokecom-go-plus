# PC-1360／PC-1360Kの全幅LCDアニメーション

作例IDは `pc1360-lcd-traverse` と `pc1360k-lcd-traverse`。ソースは共通で、MCPから対象機種のmanifestを取得できます。
内蔵アセンブラを使い、短いBASICから `CALL &C000` で一度実行します。
上段に機械語でタイトルを描き、その下の2段にまたがる画像を右端から左端まで動かします。最後の画像を残してRTNします。

- 画面は150×32ドット。各段は30列×5ブロックで、列のバイトのビット0が段の上端です。機種仕様の `directDrawing` も参照します。
- 3列の画像の左端が列147から0へ移動します。上下段の150列の窓位置は共通で、両段の描画が終わってから更新します。各段の297バイトの専用領域に最終読取りまで収めます。
- 同じ転送ループでタイトル、画像の上段、下段を描きます。各ブロックでYを設定し直し、0x303Cの記号アドレスを避けます。最後の待機は他のコマと共通です。
- 待機部は1コマ4,340サイクルで、256 kHzでは約17 msです。描画と座標更新の時間は別に加わります。
- X/Yとスタックを復元します。A・P・Q・DP・フラグは作業用で、ポートCや漢字ROMを操作しません。
- コード・データは0xC000から配置します。ROMの作業領域やBASICと重ならないか、対象SessionのRAM構成で確認してください。

合成ROMで全148コマの表示・書き込みアドレス、待機、記号アドレスの維持、呼出し元への復帰を確認する作例です。実ROM・実機の表示は別途検証します。
