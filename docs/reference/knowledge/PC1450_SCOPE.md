# PC-1450の解析・生成・実行

- ソースはPC-1450用S1 BASICの行番号付きUTF-8テキスト。BASICの標準開始位置は `0x2030`、管理ポインターは `0x5F01..0x5F04`。
- 物理RAMは `0x2000..0x5FFF`。RAW・DMPの解析とCALL先は書き込み可能な物理RAMに限る。
- LCDは16文字×1行、論理80×7ドット。停止後のピクセルとPNGをMCPで取得できる。
- 登録済みROMの起動を待ち、PROモードでビルド済みのBASICをロードしてからRUNモードへ切り替える。
  BASICのコマンド待ちから上限付きRUN／CALLを提案する。ロードと実行にはStudioでの承認が必要。
