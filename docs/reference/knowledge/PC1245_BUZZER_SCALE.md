# PC-1245の192 kHz向け音階作例

`pc1245-buzzer-scale` は内蔵アセンブラで組み立て、短いBASICの `CALL &C500` からド・レ・ミ・ファ・ソを一度鳴らして戻る作例です。
音階テーブルと発音ループを共用します。引数はなく、短いBASICと共存するよう作例のコードとデータを0xC500〜0xC5FFに収めています。

1周期はCoreで `50 + 22 × N` サイクルです。Nが31、27、24、23、20のとき、192 kHzで約262、298、332、345、392 Hzです。
各音を96周期鳴らすので、音の長さは約0.24〜0.37秒です。発音開始・終了と音の切替には追加の処理時間があります。
I、X、内部RAM[8]、ポートCを復元してRTNします。A・P・Q・DP・フラグは作業用です。
発音時はポートCの音モードだけを変更し、LCD有効ビットを保ちます。ポートCのビット1がセットされていれば、OUTCはCoreのタイマーもリセットします。

合成ROMによるCoreテストで、ポートCの波形、192 kHzでの周期、PCM生成、復帰を検証します。実機の音程と音量は未確認です。
