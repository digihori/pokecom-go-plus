# PC-1245の1行LCDスクロール

`pc1245-hello-scroll` は独自の5×7字形でタイトルを描き、1ドットずつ左へ移動してBASICに戻る作例です。
内蔵アセンブラと短いBASICからの `CALL &C500` を使います。コードと字形は0xC500〜0xC5FFに収めています。
BASICやROMの作業領域との共存は、対象のRAM構成とBuild／Loadで確認してください。

- LCDは80×7ドットです。列0〜59は0xF800から昇順、列60〜79は0xF87Bから降順。
  2つの物理範囲を別々に扱い、0xF83Cと0xF83Dのシンボルには書き込みません。
- 作例は字形転送と2区間のスクロールをループ化し、境界の列60から列59への引き渡しを処理します。
  小さなスプライトに応用するときも、両区間の一番端の読み書きと旧位置の消去を確認します。
- 192 kHzでは約0.1秒ごとに更新し、約8秒で終了します。入力はなく、I・J・X・Yを復元し、A・P・Q・DPとフラグを作業用に使います。
  ポートCのLCD有効ビットをセットします。

合成ROMによるCoreテストで全80コマと呼出し元への復帰を確認しています。任意の実ROMや実機での表示は未確認です。
