# PC-1251／PC-1401／PC-1450／PC-1460／PC-1470UのLCD境界描画

`pgp_get_example` に対象機種と表の作例IDを渡すと、内蔵アセンブラ用のAssembly、短いBASIC、対象機種のmanifestを取得できます。実装は共通で、配置・VRAM・転送方向を機種ごとに設定します。

| 機種 | 作例ID | BASICの入口 | 使用列と画素アドレス（左から順） |
| --- | --- | --- | --- |
| PC-1251 | `pc1251-lcd-boundary` | `CALL &C100` | 58〜61、0xF83A、0xF83B、0xF87B、0xF87A |
| PC-1401 | `pc1401-lcd-boundary` | `CALL &4400` | 38〜41、0x6026、0x6027、0x6067、0x6066 |
| PC-1450 | `pc1450-lcd-boundary` | `CALL &5000` | 58〜61、0x703A、0x703B、0x707B、0x707A |
| PC-1460 | `pc1460-lcd-boundary` | `CALL &C000` | 28〜31、0x301C、0x301D、0x302D、0x302E |
| PC-1470U | `pc1470u-lcd-boundary` | `CALL &C000` | 58〜61、0x283A、0x283B、0x2A00、0x2A01（上段） |

引数はなく、機種の可書込みRAMにコードと画像を置きます。BASICやROMの作業領域との重複は、対象SessionのRAM構成で確認します。2列の画像が右側から左側へ3コマ移動し、最後に使用した4列を消去します。共通のフレームループで位置を1回ずつ更新し、ブロック境界でYを設定し直します。右側のアドレスが降順なら `DYS`、昇順なら `IYS` を使います。LCDの記号領域と残りの画素には書き込みません。

各コマの待機は17,348サイクルです。秒数は対象機種の `cyclesPerSecond` で割って求め、描画と位置更新の時間を加えます。X・Y・スタック・ポートCの値を復元してRTNします。A・P・Q・DP・フラグは作業用です。OUTCは保持したポートCのビット1の状態によってCoreのタイマーをリセットする場合があります。

合成ROMで、MCPから取得したソースのコンパイル、全3コマ、書き込み先、待機、消去と復帰を検証します。実ROMと実機は未確認です。
