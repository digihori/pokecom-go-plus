# PC-1350の短いLCD描画作例

用途は、3列の画像を1ドットずつ左へ移動しながら、PC-1350のVRAMブロック境界をまたいで転送すること。
対象は、内蔵SC61860 assemblerを使うPC-1350。BASICの `CALL &6000` から呼び出す。
引数はなく、機械語と画像データを置く0x6000からの領域をBASIC・変数と重ならないよう確保する。
画面上端のx=27〜32を専用に使い、最後に消去する。ROM描画で上書きされる場合がある。

- 画像は `DB` の列データ。ビット0が上端。前後のゼロを含む6列の読取り窓を `IX` で1列進めると、画像は画面上で1列左へ動く。
- x=27〜29は0x701B〜0x701D、x=30〜32は0x7200〜0x7202。次のブロックの直前へYを設定し直し、共通ループの `IXL` と `IYS` で転送する。2ブロックの間のアドレスへは書き込まない。
- 1コマごとに `WAIT 255` を128回実行する。CoreではWAITが261サイクル、LOOPは継続時10、終了時7サイクル。待機のLIAとPUSHを含めて約0.136秒（256 kHz）。描画と座標更新の時間は別にかかる。
- X・Yをスタックに保存して復元し、RTNで呼出し元へ戻る。A・P・Q・DP・フラグは作業用。LCDの6列は上書き・消去し、ポートCは操作しない。

検証範囲は内蔵アセンブラ、BASICのコンパイル、合成ROMからのCALL、Coreでの全4コマのLCD、待機サイクル、消去、レジスター復元、RTN。実ROMと実機は未確認。
