# PC-1350の解析・生成・実行

- BASICはPC-1350のS1形式。行番号付きUTF-8テキストで渡す。特殊記号は `\PI`、`\SQR`、`\INS`、`\BX` に対応する。
- RAMの範囲は `0x2000..0x7FFF`。LCDアドレスを除いた連続RAMがRAW・DMPの解析先。BASICの標準開始位置は `0x2030`。
- LCDは25文字×4行、150×32ドット。MCPの機種仕様には、8画素の高さごとに5ブロックずつ並ぶVRAMの直接描画仕様も含む。停止中のMCP表示は全行のピクセル・PNG・シンボルを返す。
- ROMの運転モードは本体のMODEキーで選択する。上限付き実行はLCDにRUNが表示され、対象機種とプロジェクトが一致した状態で提案する。
