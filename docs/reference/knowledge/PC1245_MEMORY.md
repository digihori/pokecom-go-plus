# PC-1245のメモリとBASIC・機械語の共存

物理RAMは`0xC000..0xC7FF`の2 KiB。RAMミラーは`0xD000..0xD7FF`からの対応です。
ROM読出しaliasやLCDのaliasとは区別します。現行の既定配置は応答のCore由来データ、
実行中Sessionの配置は`pgp_get_machine_spec`で確認してください。
memoryRegionsは説明用定義であり、全アドレスへの書込み許可表ではありません。

BASICの既定本文開始と開始・終了ポインターは応答のstructured dataから取得できます。
開始・終了ポインターは下位byte→上位byteの順です。一方、assemblerのDWは上位byte→下位byteです。
両者を混同しないでください。直接ロードでは本文だけでなくナビゲーション状態等も更新されるので、
Studioの共通Build/Loadを使ってください。

HELLO WORLD作例は機械語を`0xC500`から配置し、コードと字形データを`0xC600`未満に収めます。
上位RAMはBASICの作業領域としてROMが書き換える場合があり、管理ポインターだけを避ければ安全とは限りません。
これは当該作例の配置条件で、すべてのプログラムに使える空き領域の保証ではありません。
BASICが大きい場合は機械語領域と衝突するため、Build・Loadの検証を省略しないでください。

ロード先に既存プログラムがある場合は先に保存してください。Loadと実行開始は別操作です。
ROM全体の取得は行わず、解析に必要な逆アセンブル・Traceを範囲指定で取得してください。

出典：現行Pc1245MemoryBus、Pc1245BasicDialect、RAM_1245_1261、PC-1245 HELLO WORLD作例。
任意のROM版でのワーク領域利用や、任意サイズのBASICとの共存は未検証です。
