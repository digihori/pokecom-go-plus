# PC-1360の解析・生成・実行

- S2 BASICの行番号付きUTF-8ソースを使う。キーワードと行番号参照はPC-1360用のS2形式でビルドする。BASICの標準開始位置は `0x8030`。
- RAMは `0x8000..0xFFFF`。RAW・DMPの解析とCALL先は書き込み可能な物理RAMに限る。
- `0x4000..0x7FFF` は8バンクのROM窓。RAM解析の対象から外れる。バンク切替の実行トレースは今回の検証範囲外。
- LCDは25文字×4行、150×32ドット。ROMのモードは本体のMODEキーで切り替える。LCDのRUN表示とコマンド待ちを確認してから上限付き実行を提案する。
