# PC-1261の解析・生成・実行

- BASICはPC-1261固有のS1トークン表を使う。Studioへ渡すソースは行番号付きUTF-8テキスト。特殊記号は `\PI`、`\SQR`、`\INS`、`\BX` のテキスト形式を使える。
- ハードウェア準拠の物理RAMは `0x4000..0x67FF`。RAW・DMPの解析はこの範囲に限定される。実行中のRAM構成は `pgp_get_machine_spec` で確認する。
- BASIC・アセンブリのソースを読み取り、取り込んだ機械語を逆アセンブルできる。対象のファイル名と、RAWの場合はロード先アドレスを利用者が指定する。
- 生成・ビルド・ロード・RUNはPC-1261のプロジェクトと登録済みROMを使い、Studioで操作内容を承認する。RUN/CALLの提案はBASICのコマンド待ちで行う。
- LCDは停止中にピクセルとPNGで取得できる。ROM内ルーチンの呼出規約やLCD直接描画の作法は検証範囲外。
