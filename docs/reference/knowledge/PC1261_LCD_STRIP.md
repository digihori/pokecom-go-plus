# PC-1261の2行LCD描画作例

`pc1261-lcd-strip` は内蔵アセンブラと短いBASICの `CALL &6000` を使い、上下2段にまたがる画像を1ドットずつ左に移動します。対象は120×14ドットのPC-1261です。引数はなく、0x6000からのコードと画像データをBASIC・変数と重ならないよう確保します。

- 列57〜59と60〜62を使います。上段は0x2039〜0x203Bと0x2800〜0x2802、下段は0x2079〜0x207Bと0x2840〜0x2842です。アドレスが連続していない境界をまたぐときは、Yを設定し直します。
- 各列は7画素で、ビット0が各段の上端です。上下段で同じ読み取り窓の位置を使い、両段の描画後に一度だけ位置を進めます。各段の2ブロックで同じ3列転送ループを使います。最後は12列バイトを消去します。
- 各コマの待機は34,692サイクルで、256 kHzでは約136 msです。描画と座標更新は別途時間がかかります。X・Yとスタックを復元し、A・P・Q・DP・フラグを作業用に使います。ポートCやLCDの記号アドレスには書き込みません。

MCPから取得したソースを組み立て、合成ROMで4コマの全画素、書き込み先、待機、消去、X/Yの復元とRTNを確認します。実ROM・実機での作例の動作は未確認です。
