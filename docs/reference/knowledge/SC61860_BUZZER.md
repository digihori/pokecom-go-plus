# ブザーで音階・メロディーを演奏する

この知識はStudioで対応するSC61860機種のエミュレーター実装に基づきます。
機種仕様の `cyclesPerSecond` とメモリ配置を確認してからプログラムを生成します。
BASICの発音命令の引数やROMルーチンのABIはROMごとの確認が必要です。
任意の音程を指定する作例には、BASICのCALLで起動する内蔵アセンブラ用の機械語を使えます。

## ポートCの制御

- 内部レジスター `0x5F` の値を `OUTC` で出力する。音に関わるのはビット4〜6。
- エミュレーターでは音モード2が2 kHz、3が4 kHz。音階を作るときはビット5・6を0にし、
  ビット4を交互に切り替えて矩形波を作る。モード0は低レベル、モード1は高レベル。
- 開始時にポートCを保存し、`ANIM 0x8F` で音モードだけをクリアして `OUTC`。
  出力中は `ORIM 0x10` と `ANIM 0xEF` でビット4だけを変更する。
  LCDなどに関わるビットを保持し、終了時は元の値を `OUTC` してから `RTN` で戻る。
- 高レベルと低レベルの間にそれぞれ待機を入れる。1周期の目安は `cyclesPerSecond / 周波数Hz`。
  待機ループ以外の命令のサイクルも含める。音の長さは約 `周波数Hz × 秒数` 周期で調整する。
  固定周期数で鳴らすと、音程が違う音同士で発音時間が変わる。休符は低レベルで待機する。

例えばド・レ・ミ・ファ・ソの目標周波数は順に約262、294、330、349、392 Hzです。
以下は既存のPC-1350作例で使う半周期待ちの基本部分です。上位ループでこれを必要な周期数だけ繰り返します。
半周期カウンターは1以上とし、呼出し側でIと一時レジスターを保存・復元します。

```asm
; Internal RAM 10 contains the half-period loop count.
    LIP 0x5F
    ORIM 0x10
    OUTC
    LIP 10
    LDM
    LIP 0
    EXAM
TONE_HIGH_WAIT:
    DECI
    JRNZM TONE_HIGH_WAIT
    LIP 0x5F
    ANIM 0xEF
    OUTC
    LIP 10
    LDM
    LIP 0
    EXAM
TONE_LOW_WAIT:
    DECI
    JRNZM TONE_LOW_WAIT
```

PC-1350のCoffee Breakテストはこの方式で生成されたPCMとポートCの復元を確認しています。
他機種ではCPUクロックに合わせて待ち時間を調整し、Studioで発音順、長さ、BASICへの復帰を確認します。
指定周波数の精度や実機の発音は機種ごとに検証が必要です。
