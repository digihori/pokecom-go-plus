# PC-1350 Machine Definition

**ステータス:** Core／Studio実装済み。Android Playerも予定した対応を実施し、2026-10-16にユーザーが一通りの確認を終えて今回分を一区切りとした。

**Machine ID:** `pc-1350`

**Generation:** S1（第2世代）

PC-1350は25桁×4行LCDを持つS1機種。Android Playerは機種選択・ROM管理・Session切替・本体入力・BASIC／DMPを接続した。
本体／Physical入力は手順3で接続・エミュレータ確認済み。LCD配置とBASIC／DMPの機種別検証も実施。ゲームパッド・サウンド・CPU速度も自動検証・エミュレータ確認済み。ユーザーの一通りの動作確認で今回分を一区切りとし、機器別の網羅検証とは区別する。[Androidの段階別対応記録](../../development/ANDROID_PC1350_PROGRESS.md)を参照。

## 現行実装

| 項目 | 値 |
|---|---|
| ROM | 内部8 KiB（0000〜1FFF）、外部32 KiB（8000〜FFFF） |
| legacy形式 | 64 KiBフラットイメージ |
| CPU実行速度 | 256,000 cycles/s（768 kHz発振の3分周） |
| RAMの物理範囲 | 2000〜7FFF。LCDアドレスはプログラム配置の検査で別扱い |
| LCD | 25桁×4行、1セル6×8ドット |
| Display Snapshot | 150列×32行。Playerへ物理VRAM配置を公開しない |
| LCDデータ | 20個の不連続な30-byte領域、合計600 bytes |
| シンボルアドレス | 783C |
| Snapshotのシンボル | SHIFT／DEF／RUN／PRO／KANA／SMALL |
| キーマトリクス | 12グループ。画面上のSHIFTは2か所で同じ論理入力 |
| BASIC | S1形式。標準開始位置2030、開始ポインタ6F01、終了ポインタ6F03 |

LCDデータ領域は`7000`、`7200`、`7400`、`7600`、`7800`を基準とし、
各基準の`+00`、`+40`、`+1E`、`+5E`から30 bytesずつ配置される。
4行への並べ替えはCoreの`FourLineDisplay`が行い、ホストはSnapshotを描画する。

本体のMODEキーでROMのモードを切り替える。現行Coreの`setOperatingMode`はPC-1350の
ROM状態を変更しないため、Playerのホスト要求値だけでRUN／PROを確定表示しない。

## 対象外・残る確認

- メモリーカード／RAM拡張は別作業。標準の現行実装へ混ぜない。
- ROM版差、実機の表示・キー操作、機種別入出力の検証状況はCore／StudioとAndroidで区別する。
- Android共有基盤のスキン座標は初期値。実表示とタッチ領域の一致は後続で確認する。
