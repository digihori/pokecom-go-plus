# PC-1360 Machine Definition

**ステータス:** Core／StudioはPC-1360対応済み。PC-1360Kの現在の実装・解析結果は[専用記録](PC-1360K.md)を参照。
Android Playerは[PC-1360](../../development/ANDROID_PC1360_PROGRESS.md)／[PC-1360K](../../development/ANDROID_PC1360K_PROGRESS.md)の今回の範囲は、2026-10-20にユーザーの実機確認「概ねOK」を受領済み。全端末・ROM版・周辺機器の網羅検証とは区別する。
以下の初期実装時の記述には、K固有部分が未確定だった段階の履歴を含む。
**Machine ID:** \`pc-1360\`\
**Generation:** S2（第3世代）

PC-1360は、S2系およびバンク切替機種の最初の実装対象とする。PC-1360Kの解析基盤を
共通化できることも選定理由である。

## 参照実装から確認した構成

| 項目 | 値 |
|---|---|
| 内部ROM | \`0x0000..0x1fff\` |
| 制御・LCD等 | \`0x2000..0x3fff\` |
| ROMバンク窓 | \`0x4000..0x7fff\`（16KiB） |
| ROMバンク数 | 8 |
| バンク選択レジスタ | \`0x3400\`、下位3bit |
| RAM | \`0x8000..0xffff\` |
| LCD | PC-1350と同じ25文字×4行構造 |
| シンボル | \`0x303c\` |
| キー選択補助 | \`0x3e00\` |

現在のキーボード定義は国内向けPC-1360実機の刻印を基準とする。右端キーのSHIFT割当は
\`, → <\`、\`: → >\`、\`/ → (\`、\`; → )\`、\`* → ¥\`である。
PC-1360K固有の配列は、仕様が確定するまでこの定義へ混在させない。

1360K解析用途のため、PC-1360ではマシン語イメージを`0x2000..0x3fff`へロードできる。
これには1360Kで漢字用ワークメモリとなる`0x2000..0x27ff`も含む。現時点ではPC-1360K固有の
メモリモデルを推測せず、PC-1360の書込み可能領域として扱う。

\`.pgrom\`では内部ROM 8KiBと、16KiB×8バンクを独立コンポーネントとして保持する。
Pokecom GO互換の\`pc1360mem.bin\`＋\`pc1360bank.bin\`はImporterだけが扱い、Coreへは持ち込まない。

Memory Busは現在のバンク番号を所有し、\`0x3400\`へのWrite時にバンク切替イベントを発行する。
デバッガの命令トレースには論理PCだけでなく、バンク番号と物理ROM位置を記録できるようにする。

参照コードにはFOによるRAMバンク選択らしき処理がある一方、実際のbanked RAM読書きは
コメントアウトされている。この部分は推測実装せず、資料または実機確認まで未確定とする。
PC-1360Kの漢字ROMと漢字ワークRAMもPC-1360実装へ混在させず、追加コンポーネントとして扱う。

## Player対応時のスキン注意事項（2026-10-16）

ユーザー提供のPC-1360／PC-1360Kスキンでは、キーレイアウト上の都合で右側SHIFTを省略している。
Player接続時は左側SHIFTのみを画面キーとして扱い、PC-1350の左右2か所のSHIFT領域を流用しない。
スキン資産の存在や更新をPlayer機種対応完了とは扱わない。今回の記録は将来実装時の注意であり、
PC-1360／PC-1360KのPlayer対応やCoreのキー構成を変更するものではない。

## BASIC置換後の編集状態（2026-10-31）

PC-1360/1360KはBASICの直接・結合ロード成功時にCPU内部RAM `0x35` のbit `0x10`
（旧RUN位置からの編集復帰状態）を解除する。開始・終了pointerの更新だけでは、
短縮後に上キーで旧領域を読み、カーソル位置や行表示が崩れることがある。
ロード失敗・BASICを含まない操作ではこの状態を変更しない。
ローカルROMで、NEW後に手入力したshort.basとのカーソル込みの表示比較を行う。
