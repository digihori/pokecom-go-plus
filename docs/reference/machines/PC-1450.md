## 採用した定義

| 項目 | 今回の値・根拠 |
|---|---|
| CPU | 768 kHz / 3 = 256,000 instruction cycles/s（Pokecom GO CLOCK、PockEmul frequency） |
| ROM | 内部8 KiB `0000..1fff`、外部32 KiB `8000..ffff` |
| ROM取込 | 64 KiBの `pc1450mem.bin`、または内部／外部の個別dump。RAM内容は取り込まない |
| RAM | 固定16 KiBカード相当 `2000..5fff`。容量選択は追加しない |
| 制御窓 | `6000..7fff` は参照に合わせた互換窓。全域を物理RAMと主張しない |
| LCD | 16桁×1行、5×7。`7000..703b` → columns 0..59、`7068..707b` → 79..60（反転） |
| symbol | `703c`（カナ／小／SML／STAT）、`703d`（BUSY／DEF／SHIFT／HYP／PRO／RUN／CAL）、`707c`（E／M／括弧／RAD／G／DE／PRINT） |
| キー | `7e00`の最下位set bitでgroups 0..6、IA最下位set bitでgroups 7..12。INB=`38` |
| BASIC | S1。初期text `2030`、start/end pointer `5f01..5f04`、text上限 `5c30` exclusive |

BASIC上限は [PC-1450の実機メモリ観測](https://ht-deko.com/pc1450/) の16 KiB構成の
`2030..5c2f` に基づく。開始／終了markerを含めた格納上限であり、変数領域まで含む最大プログラムの実機保証ではない。

PC-1401とCPU、buzzer、モード入力queue、S1の行構造を再利用する。RAM、LCD配線、
selector、キー表、語彙は1401の値で代用しない。`DECI`、`FACT`、`MARGE`、OPEN/SAVE系等は
1450/1460の参照語彙。半角カナは `FE` prefix、特殊表示は `FB`=π、`FC`=√、`F9`=block。

Pokecom GOは1450にもKeyBoard1460を使いF↔E／STATを欠く。
[PockEmulの1450固有表](https://github.com/matsumo/PockEmul/blob/8c07fd1ff027e7ee69056b5d8273afbbf14037a8/src/core/Keyb1450.h)
で、IA bit 0 groupのbit 3=F↔E、bit 2=STATを補う。コードコピーはしない。
第2SHIFT位置はGOのLOCK scanを採用する。刻印画像との違いを実機で再照合する余地がある。
SHIFTの2位置はStudioで別の入力所有者として扱う。

Studioは論理ドットを変更せず正方形の物理dot pitchを使用する。
CAL/BASIC/BRK、カナ／濁点／長音、主キーと6列×3行の関数キーを表示する。

## 確認の区分

- 合成: ROMサイズ・RAM破棄、LCD区画端／symbol、selector／IA／BRK、BASIC語彙・カナ・入出力、容量／pointer／ロード境界、失敗時の無変更。
- ローカルROM: 起動、CAL→RUN→PRO→RUN→CAL、BASIC直接ロード、FACT(5)とPOKEによる120の書込み、ERRORなし。
- Studio: `.pgrom`生成／復元、機種間取り違え拒否、全画面キーのCore受付、Project starter、物理dot比率を自動検証。
- 実機照合／Windowsでの手動操作／最大容量／全ROM版／周辺機器は別の未確認項目。
