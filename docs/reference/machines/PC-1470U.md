## LCDとキーの固有差

LCDは24桁×2行、各文字5×7。

| アドレス | LCD位置 |
|---|---|
| `2800..283b` | 1行目 columns 0..59 |
| `2a00..2a3b` | 1行目 columns 60..119 |
| `2840..287b` | 2行目 columns 0..59 |
| `2a40..2a7b` | 2行目 columns 60..119 |

symbolは1450/1460と違う。
`283c`=BATT／括弧／HYP／AER／PRO／RUN／CAL、`283d`=BUSY／DEF／SHIFT／DBL、
`287c`=E／M／RAD／G／MATRIX／STAT／PRINT、`287d`=カナ／小／SML／DE。
Studioは正方形dot pitchと1-dotの行間を使う。

DEL／BS／INSは1460のX↔M／RM／M+とは違う独立scan。
左右SHIFTは同じCore keyに別のStudio入力所有者を持つ。
キー画像で通常AER／SHIFT CALを確認し、OperatingModeにもAERを区別して追加した。
CAL要求はSHIFT→AER keyのqueue、AER要求はAER keyのqueue。
物理キーボードのBackspace／Deleteは1470UだけBS／DELへ接続する。

S2行処理は既存1360を再利用し、**1470U固有token table**を渡す。
1360のGCURSOR、LINE、POINT、PSET/PRESET、漢字関数等を1470Uへ混在させない。
