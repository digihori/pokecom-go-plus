# PC-1260 / PC-1261 — Core / Studio

## シリーズ方針（2026-10-14）

ユーザー合意に基づき、シリーズ内の機種差はユーザーメモリ容量として扱う。
external ROMの複数版は機種差にせず、ユーザーが用意したROMを使用する。
特定の既知hashやROM内のhook addressを動作条件にしない。
PC-1262はPC-1261の価格改定版なので、独立した選択ラインナップには加えない。PC-1261を選択する。

| 項目 | PC-1260 | PC-1261（1262相当を含む） |
|---|---|---|
| Machine ID | `pc-1260` | `pc-1261` |
| 物理外部RAM | `5800..67ff`（4 KiB） | `4000..67ff`（10 KiB） |
| BASIC既定開始位置 | `5880` | `4080` |
| start/end pointer | `66e1..66e4` | 同左 |
| CPU / LCD / キー / BASIC | 1261既存実装を共用 | 24桁×2行、S1 |
| ROM | internal 8 KiB＋external 32 KiB | 同左 |

BASIC writerは機種別既定開始位置を使い、初期化済みの有効なstart pointerがあれば尊重する。
既存writerの上限`66e0` exclusiveは維持し、実機の固定変数・work領域まで含めた
最大ユーザー容量を新たに確定したものとはしない。

容量に依存するRAMミラーは、ユーザー指示で保留。実機でミラーしていない可能性もあるため、
物理RAM外へ新しいRAM aliasは追加しない。従来のLCD decode／LCDミラーは維持する。

## Studio / ROM

機種選択、ROM component／64 KiB legacy取込、`.pgrom`作成、BASIC codec、
BASIC／addressed memory／Projectロード、キー入力とLCDは選択機種を保持する。
シリーズ内ではROM登録を共用し、既存Libraryの`pc-1261/active.pgrom`を継続利用する。
別シリーズROMは拒否し、サイズ・component構成・package hashの整合性検査を維持する。
hashはpackageの破損検査であり、ROM版のallowlistではない。

Projectの機種互換方針、Playerの新機種skin／選択、Expanded RAMモードは変更しない。
1350／1460等のメモリーカード拡張は本対応後の別項目。

## 検証区分

- 合成: 任意のROM版byte列、機種identity、RAM端／範囲外・reset・セッション分離、BASIC既定位置／pointer／往復／容量超過時の原子性、ProgramImageLoader。
- Studio: component／legacy／package identity、同シリーズROM共用、別シリーズ拒否、既存Libraryパス、キー入力、全機種LCD比率の回帰。
- ローカルROM: ignored local-dataの1261用internal/externalを使い、1260／1261両容量でNEW後の開始pointerとBASIC POKE実行を確認。全ROM版の保証や実機検証とは区別する。
- 実機・Windowsユーザー操作・RAMミラーは未確認。
