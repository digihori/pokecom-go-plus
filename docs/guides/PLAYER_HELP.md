# Pokecom GO Playerとは

更新日: 2026-10-20

Pokecom GO Playerは、Pokecom GO Studioのエミュレータ実行部分を切り出した、ポケットコンピュータの操作とプログラム実行を楽しむためのアプリです。画面上の本体やキーを操作し、実機のポケコンを手にして使うような雰囲気を再現します。

BASICプログラムやマシン語プログラムを読み込み、ポケコンのキーで操作できます。本体で入力・編集したBASICプログラムをファイルへセーブできます。プログラムの作成や詳しい解析にはPokecom GO Studioを利用できます。

## 対応機種とROM

現在のAndroid PlayerはPC-1245／PC-1251／PC-1261／PC-1350／PC-1360／PC-1360K／PC-1401のユーザー確認を終えています。PC-1450／PC-1460／PC-1470Uもユーザーの実機確認を終えています。シリーズ内の追加モデルPC-1250／PC-1255／PC-1260／PC-1402は別途実機確認が必要です。機種選択・ROM管理・本体操作・BASIC保存とBASIC／DMPロード・ゲームパッドを利用できます。ROMは同梱していません。ご自身で適法に入手したROMを登録してください。

## 始めるには

ホーム上部または「設定」→「ROM管理」の「はじめに・ROMの準備方法 / Setup guide（外部）」から、日本語・英語のセットアップガイドを外部ブラウザで開けます。ROMが未登録でも利用できます。「Playerとは」「Studioについて」にも同じ入口があります。

ホーム・設定・ヘルプは端末の縦横とシステムの自動回転設定に追従し、機種画面だけ横向きに固定します。ホームの機種は名前順に表示します。一覧が画面に収まらない場合は、タイル・リストとも右側にスクロール位置のバーを表示します。右上の「タイル」「リスト」で表示形式を切り替えられ、次回起動にも引き継ぎます。選択中の機種は、名前の先頭に`*`を付けて表示します（例：`*PC-1360K`）。機種画面との往復ではタイル・リストそれぞれのスクロール位置を保ち、ホームへ戻ったときや回転後に選択中の機種が見えなければ、その位置へ移動します。

ホームで機種ごとの「ROMを登録」からpgromまたはその機種のlegacy ROMを選び、登録後に「プレイ」を押します。pgromは同じシリーズ内で共有できます。別シリーズのROMは登録できません。legacy ROMはファイルサイズから機種を自動判定しません。PC-1245／PC-1250・1251・1255は32／64KiB、PC-1260・1261／PC-1401・1402／PC-1350／PC-1450は64KiBのフラットイメージを扱います。PC-1360／PC-1360K／PC-1460／PC-1470UはStudioで作成したpgromを使用します（単一flat画像は扱いません）。Kの漢字字形・辞書には4領域の漢字ROMを含むpgromを使用してください。初回はCPUを自動実行します。

PC-1250／1251／1255、PC-1260／1261、PC-1401／1402は、ホームの機種名のプルダウンでモデルを選びます。各シリーズの選択は自動保存され、表示形式を変えたりアプリを再起動しても維持します。選択変更だけでは動作中のSessionは変わりません。「プレイ」を押し、確認後に切り替えます。選択モデルと起動中モデルが違うときは「起動中：…」を表示します。

ROMはシリーズ単位で1セットを共有し、登録・置換・削除がシリーズ全体に適用されます。ROM管理の「使用する」はホームで選択したモデルを起動します。各モデルの標準RAM構成を使用し、RAM拡張の選択はありません。PC-1401／1402はROM版によって容量認識が異なり、1401のROMが1402容量を認識するとは限りません。必要に応じてシリーズ共通ROMを置き換えてください。

別の機種へ切り替える際は、確認後に新しいSessionを開始します。現在のRAMとロード済みプログラムは失われます。同じ機種のホームとの往復ではSessionを維持します。ROMの登録・置換・削除・選択はアプリ内へ保存しますが、RAMや実行状態はアプリ終了後に復元しません。

## ポケコンのモードとCPUの実行

RUN/PROはポケコンの動作モードです。PC-1245／PC-1250・1251・1255／PC-1260・1261ではタイトルバー右側のボタンでRUN／PROを切り替えます。PC-1250・1251・1255／PC-1260・1261のRSVは動作モードメニューから選びます。PC-1401・1402／PC-1450／PC-1460の起動・Reset後はCALから始まります。PC-1470UはLCDのモード表示を確認してください。PC-1401・1402／PC-1450／PC-1460は本体のCAL／BASICキー、PC-1470UはAER（SHIFTでCAL）／BASICキーでモードを切り替えます。メニューの「動作モード」はPC-1245／1251／1261系だけに表示します。「エミュレータ操作」のRun/PauseはCPUの実行・停止で、BASICのRUNコマンドとは別です。タイトルバーの状態表示をタップしてもCPUのRUN/PAUSEを切り替えられます。Resetはメニューから行います。

ホームへ戻るとCPUを停止します。実行中から戻った場合は再入場で再開し、停止中から戻った場合は停止を維持します。背景からの通常復帰は停止状態です。

## プログラムのロード・セーブ

「プログラム」の「ロード」からUTF-8 BASICテキスト（.bas）とPGP Memory Dump（.dmp）を読み込めます。上限は2 MiBです。BASICは全体を置換し、DMPは記載アドレスのRAMを上書きします。DMPでBASICが壊れる場合があります。

BASIC・DMPともロード成功後はCPUを自動実行します。BASICの実行にはポケコン側でRUNを入力してください。「セーブ」は全機種共通でBASIC（.bas）のみをファイルへ保存します。DMPはロード専用です。実行中にセーブを開いた場合は終了後にCPUを再開し、明示的に停止してから開いた場合は停止を維持します。キャンセル時も開始前の状態へ戻ります。

PC-1401のBASICはS1形式として変換し、セーブ時には空白などが正規化される場合があります。PC-1401のRAMは3800〜47FFです。ROM・LCDなどRAM以外の範囲へDMPをロードできません。DMPはBASIC本体や管理情報も上書きできるため、必要なBASICは先にセーブしてください。ロードのキャンセル・失敗時は停止状態です。

## データを残すには

ROMの置換・Session切替や、使用中ROMの削除では現在のRAMとプログラムを失います。セーブステートはありません。アプリ終了前に残したいプログラムを保存してください。

Project、Assembler、Debugger、WAV入出力はPlayerの対象外です。


## 外部キーボード（Physical）

プレイ画面でCPU実行中は、外部キーボードのキーを押している間、対応するポケコンのキーを押します。文字変換やIMEによる入力は行いません。ShiftはポケコンのSHIFT、左CtrlまたはF1はDEF、EscはBRK、Backspace/DeleteはCL（PC-1350ではBackspaceがCLS、DeleteがDEL）、矢印・Enter・Spaceは対応する本体キーです。

英字・数字とテンキー、+、-、*、/、.、=は対応する本体キーへ送ります。PC-1401／1402ではF2をCAL、F3をBASICへ割り当て、テンキーの括弧キーも受け付けます。PC-1350／PC-1360／PC-1360KではF2をMODE、F3をカナ、InsertをINS、DeleteをDELへ割り当てます。PC-1360／PC-1360KはF4がSML、PC-1360KはさらにF5が漢字、F6が平／片、F7が採用、F8が変換、F9が▲▼です。PC-1450／PC-1460はF2=CAL、F3=BASIC、F4=カナ、F5=SML、F6=濁点、F7=長音、F8=左SHIFT刻印（1450）／LOCK（1460）です。PC-1470UはF2=AER（SHIFTでCAL）、F3〜F7は同じ、F8=SHIFT、Backspace=BS、Delete=DEL、Insert=INSです。PC-1470Uの左右SHIFTは同じ論理キー、1450／1460の左側はLOCKスキャンで、右側SHIFTとは区別します。関数キーなど、それ以外の固有キーは画面上で操作できます。同時押しはポケコンのキー刻印に従います。PCのShift+数字などを記号へ変換する方式ではありません。ホーム・メニュー・ダイアログ・停止中はエミュレータへ送りません。背景移行・モード切替・キーボード切断時には押下を解放します。

PC-1245／PC-1401では短い押下もROMが読めるよう、機種定義にある自動入力と同じ最小CPUサイクル数だけ保持します。短い連続入力は順番と解放間隔を保ち、長押しと同時押しも扱います。停止・背景移行では即座に解放し、未入力のキーを破棄します。

## ゲームコントローラー

ホームの「設定」→「コントローラ設定」で有効にし、十字キー4方向・フェイスボタン4個・L1／R1にポケコンのキーを割り当てます。OSで認識済みのUSB／Bluetoothコントローラーを1台選んで使います。接続・ペアリングはAndroid側で行ってください。スティック・トリガー・連射・振動は扱いません。

割当は全機種で共通の1セットで、変更すると自動保存されます。現在の機種のキーから選択でき、PC-1401ではCAL・BASIC・関数キーも割り当てられます。他の機種で使えないキーの割当は消さずに保持し、その機種では入力しません。設定中のボタン操作はテスト表示だけで、ポケコンへ送りません。

押している間はキーを保持し、離すと解放します。複数ボタンに同じキーを割り当てた場合や、画面・外部キーボードの同じキーと重なった場合も、すべて離すまで保持します。ホーム・メニュー・停止・背景移行・切断・割当変更などで解放し、復帰後は一度ボタンを離してから押し直してください。ゲームパッドの短押しには外部キーボードの最小保持補正を適用しません。

## サウンドとCPU速度

ホームの「設定」→「サウンド」で、全機種共通の音声出力をON／OFFにできます。初期値はONです。音量は端末のメディア音量で調整してください。音量キーもメディア音量を操作します。ポケコンのブザー音を再生し、録音は行いません。

ホーム・CPU停止・背景では音声を停止し、復帰後に過去の音を再生しません。他のアプリが音声を使用すると、CPUは継続したまま音声だけ停止します。一時的な音声フォーカス喪失では前景・実行中の場合に復帰します。ヘッドホン切断・恒久的なフォーカス喪失・出力エラーの後は、CPUの再開またはサウンドOFF→ONで再試行できます。

「設定」→「CPU速度」で0.8／0.9／標準（1.0）／1.1／1.2倍を選択できます。初期値は標準です。各機種の標準クロックに対する倍率で、全機種共通に保存します。Resetや機種切替でも設定を維持します。速度の変更だけではRAMやCPUの実行位置を初期化せず、停止中なら停止を維持します。端末の性能によっては目標速度に達しない場合があります。

速度に合わせて音の高さとテンポも変わります。無制限モードはまだありません。
