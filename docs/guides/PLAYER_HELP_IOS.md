# Pokecom GO Playerとは

Pokecom GO Playerは、Pokecom GO Studioのエミュレータ実行部分を切り出した、ポケットコンピュータの操作とプログラム実行を楽しむためのアプリです。

iPhone版はPC-1245、PC-1250／1251／1255、PC-1260／1261、PC-1350、PC-1401／1402、PC-1450、PC-1360、PC-1460、PC-1470U、PC-1360Kに対応しています。ROMは同梱していません。ご自身で適法に入手したROMを登録してください。最低iOS 16、iPhone専用です。

ホーム・設定・ROM管理・プログラム入出力・情報画面では縦／横の両方を利用できます。ポケコン本体の機種画面だけ横向きに固定します。ホームは機種名順に並び、「タイル／リスト」で切り替えられます。初期表示はタイルで、選択した表示形式は次の起動にも引き継ぎます。タイルの列数は画面幅に合わせて変わります。

## 始めるには

ホームで機種を選び、「ROMを登録」からpgromまたは単体ROMを選びます。単体ROMはPC-1245・PC-1251系が32／64 KiB、PC-1261系・PC-1350・PC-1401系・PC-1450が64 KiBです。PC-1250／1251／1255、PC-1260／1261、PC-1401／1402はそれぞれ同じカードのプルダウンで選択し、シリーズ内でROMを共用します。PC-1360・1360K・1460・1470Uは内部ROMと全ROMバンクを含むpgromのみ対応します。Studioで作成した機種別のpackageを登録してください。単体画像やバンクファイルだけでは登録できません。単体ROMの機種は選択したカードで決まります。登録後に「プレイ」を押すとCPUを自動実行します。

モデルの選択だけでは起動中のRAMを変更しません。異なるモデルの「プレイ」で確認し、確定後に標準RAM構成の新しいSessionへ切り替えます。選択モデルと起動中モデルは別々に保存され、再起動時には起動中モデルを停止状態で復元します。PC-1250のMEM表示が大きくなる場合がありますが、現在は既知の保留事項です。PC-1402も容量認識の実ROM確認を保留しており、ROMからモデルを自動判別しません。

ROMはアプリ内Libraryへ取り込み、以後は元ファイルへ依存しません。同じSessionでホームを往復してもRAM・モード・表示を維持します。実行中からホームへ戻った場合は再入場で再開し、明示Pause後は停止を維持します。通常の背景復帰は停止します。

## CPUとポケコンのモード

タイトルバーのRUNNING／PAUSEDをタップするとCPUを停止・再開できます。「エミュレータ操作」にもRun／Pause／Resetがあります。Resetは初期化後にCPUを自動実行します。PC-1245・1251系・1261系はRUNへ戻り、その他の機種はROMの初期化に従います。FAULTED時はResetしてください。

RUN／PROボタンはポケコン本体のモード切替で、CPUのRun／Pauseとは別です。PC-1245・1251系・1261系の右上ボタンはRUN／PROだけを切り替えます。RSVは「動作モード」メニューで選択してください。RSV選択中も右上はRUNと表示し、押すとPROへ切り替わります。PC-1250／1251／1255とPC-1260／1261はRUN／PRO／RSV、PC-1245はRUN／PROです。LCDのRUN／PRO／RSVは左から順の固定位置に並び、選択中のモードだけが点灯します。PC-1245にはRUN／PROのみを表示します。PC-1350・1360・1360Kは本体のMODEキーで切り替え、右上ボタンと動作モードメニューは表示しません。PC-1350・1360・1360Kのモード表示はROMが制御します。PC-1401／1402・1450・1460は本体のCAL／BASICキー、PC-1470UはAER（SHIFTでCAL）／BASICキーを使用します。右上のRUN／PROトグルと「動作モード」メニューはPC-1245・1251系・1261系だけに表示します。PC-1401／1402・1450・1460・1470UのLCDのモード表示はROMに従います。「表示」で通常／Controller Displayを切り替えられます。

## ロードとセーブ

「プログラム」→「ロード」でUTF-8 BASICテキスト（.bas）かPGP Memory Dump（.dmp）を選びます。2 MiBまでです。BASICは全体を置換し、DMPは記載アドレスのRAMを上書きします。DMPはBASIC本体や管理情報を破壊する場合があります。ROM・LCD・制御領域やミラー重複は拒否します。

PC-1360・1360K・1460・1470UはS2 BASICに対応します。実ROMの初回RAM確認などの初期化を済ませてから、プログラムをロードしてください。

ロード成功後はCPUを自動再開します。BASICのRUNコマンドは自動入力しません。取消・検証失敗ではメモリを変更せず、停止を維持します。

「セーブ」はBASIC全体か、開始・終了を16進数で指定したRAM範囲を保存します。終了アドレスも含みます。保存先は標準ファイル画面で指定します。他アプリへの共有はありません。実行中から開いた場合はセーブ終了後に再開し、明示Pauseから開いた場合は停止を維持します。キャンセルでも同じ方針です。通常の背景移行では再開意図を取り消します。

## Filesとクラウド

「このiPhone内」とiCloud Driveなど、標準ファイル画面に表示される場所を選べます。Google Driveは利用者がDriveアプリを設定し、「ファイル」で有効にした場合に候補になります。表示・取得は認証やネットワーク、提供元の状態に依存します。

Player独自のログイン・クラウド同期はありません。クラウド提供元が取得・同期のために通信する場合があります。ファイルへのセーブ完了はクラウド同期完了を意味しません。

## サウンド・CPU速度

ホームの「設定」から変更します。CPU速度は0.8／0.9／1.0／1.1／1.2倍で、音高・テンポも同じ倍率に追従します。初期値は1.0倍・サウンドONです。設定は次の起動にも引き継ぎます。

サウンドはiPhoneの消音モードに従い、他アプリの音声と共存します。Pause／Reset／ホーム／背景移行では未再生の音声を破棄します。背景再生はありません。音声割込み後はOSが再開を許可し、Playerがまだ実行中の場合に新しい音声から再開します。

ヘッドホン切断や音声出力エラー後は自動でスピーカーへ鳴らさず、Pause→RunまたはサウンドONで再試行します。ホームのサウンド設定にも再試行ボタンがあります。音声エラーはCPUの故障状態にはしません。

## ゲームパッド・Physical外部キーボード

ホームの「設定」→「コントローラ設定」で有効化し、図の10入力へ対応機種のキーを割り当てます。選択機種にないキーは送出しません。初期状態はOFF・未割当です。全体共通の1セットを自動保存します。未接続でも編集でき、設定中の押下は点灯確認だけです。

OSで接続済みのGameController対応パッドから1台を使用します。複数接続時は使用機器を選択します。選択機器の切断後、接続中の別機器へ勝手に切り替えません。機器やprofileにより利用できない入力があります。十字キー・フェイス4位置・L1/R1のみを使い、スティック・トリガーは対象外です。A/B/X/Yの印字が異なってもボタンの位置で選びます。

外部キーボードはPhysical入力です。文字変換・IMEは使いません。英数字・矢印・テンキー、単独SHIFT、左Control/F1→DEF、Esc→BREAK、Backspace→CLEAR等を使用します。Shift+数字から記号を生成しません。Option/CommandはOS操作へ残します。PC-1350・1360・1360KではF2→MODE、F3→カナ、Insert→INS、前方Delete→DELを使用できます。PC-1360／1360KはF4→SMLも使用できます。BackspaceはCLEARです。PC-1401／1402・1450・1460・1470UではF2→CAL、F3→BASIC、PC-1450・1460・1470UではF4→カナ、F5→SML、F6→濁点、F7→長音、F8→SHIFTロックも使用できます。ただしPC-1470UのF8はSHIFTで、Backspace→BS、前方Delete→DEL、Insert→INSになります。

Pause、メニュー、モーダル、ホーム、背景、フォーカス喪失や切断で保持入力を解放します。復帰時は保持中の入力を再送せず、一度離してから押してください。Controller Displayでも外部入力は利用できます。OS側での接続・ペアリング設定が必要で、アプリ独自のBluetooth通信は追加していません。

## PC-1360Kの漢字ROMと入力

PC-1360Kは専用pgromを登録します。漢字ROMはselector 0〜3（各64 KiB、role `kanji`）です。従来の漢字ROMなし／selector 0・1のみのpackageも登録できますが、漢字機能を十分に利用するには4個すべてが必要です。通常のPC-1360とはROMを共用しません。F5→漢字、F6→平／片、F7→採用、F8→変換、F9→￥を使用できます。LCDの平・片・反転Sを表示します。BASICファイルの文字コードはS2の既存範囲で、全角日本語のファイル変換には対応していません。

## データと現在の対応範囲

ROMの置換・削除はシリーズ全体へ適用され、同シリーズの起動中モデルも対象です。ROM置換、または起動中シリーズのROM削除では現在のRAMとプログラムを失います。RAM・CPUのセーブステートはなく、アプリ終了を越えた復元は行いません。残したいプログラムはファイルへセーブしてください。

Project、Assembler、Debugger、WAV入出力はPlayerに含みません。プログラムの作成・詳しい解析にはStudioを利用できます。

対応機種の接続は実装済みです。追加機種の自動回帰検証には独自の合成ROMとSimulatorを使用しています。対応機種一通りの動作と音声再生を確認しました。音声の途切れ感は今後の調整項目です。最低iOS 16、実周辺機器・クラウド提供元など環境別の詳細確認は引き続き管理します。
