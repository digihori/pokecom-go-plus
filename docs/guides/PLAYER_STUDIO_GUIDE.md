# Pokecom GO Studioについて

更新日: 2026-10-22

Pokecom GO Studioは、レトロなポケットコンピュータ向けプログラムを現代のPC上で作成・実行・解析し、実機への転送まで支援するマルチプラットフォーム開発環境です。

macOS／Windows／Linuxで利用できます。Project管理、BASIC編集、内蔵アセンブラー、外部アセンブラー連携、Debuggerなどを備えています。実機への転送支援には対応形式・手順の制限があるため、配布版の説明を確認してください。

Studioで用意した、その機種に対応するBASICテキスト（.bas）やPGP Memory Dump（.dmp）をPlayerへ渡し、「プログラム」から読み込めます。ProjectそのものやWAVはPlayerへ読み込めません。

2026-10-22時点のAndroid版とiPhone版Playerは、PC-1245、PC-1250／1251／1255、PC-1260／1261、PC-1350、PC-1401／1402、PC-1450、PC-1360、PC-1360K、PC-1460、PC-1470Uに対応しています。StudioとPlayerでは操作や利用できる機能が異なります。iPhone版はiPhone専用・最低iOS 16です。配布版ごとの対応範囲と既知の制限は各リリースの説明を確認してください。ROMはどちらにも同梱していません。
