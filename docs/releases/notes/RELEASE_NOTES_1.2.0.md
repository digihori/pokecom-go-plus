# Pokecom GO Player 1.2.0

## 日本語

- ゲームパッドの左スティックを移動に使えるようになりました。右スティックの各方向とL1／L2／R1／R2にはポケコンのキーを割り当てられます。
- Androidで複数のゲームパッドから同時に入力できるようになりました。初代Joy-Conの左右を組み合わせて操作できることを確認しました。
- Androidで、一部のBluetoothヘッドフォンを接続すると音が出ない問題を修正しました。

[日本語のストア更新文](../store/1.2.0/whats-new.ja.txt)

## English

- Use the left analog stick for movement. Assign pocket computer keys to each direction of the right stick and to L1, L2, R1, and R2.
- Android now accepts input from multiple gamepads at the same time. Using a pair of original Joy-Con controllers together was verified.
- Fixed an issue that prevented audio playback on Android with some Bluetooth headphones.

[English store update text](../store/1.2.0/whats-new.en.txt)
