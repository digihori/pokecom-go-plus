2. Purpose and target audience

Pokecom GO Player is an offline emulator for classic programmable pocket computers. It is intended for pocket-computer owners, enthusiasts, and people interested in BASIC programming. Users operate an on-screen keyboard and LCD, run their own programs, and import/export program files. It provides access to these devices' programming experience on an iPhone without carrying the original hardware, using ROM files the user is authorized to use.

3. Setup, main features, and sample file

No login, external hardware connection, or paid service is required. A compatible ROM is required to run an emulated machine; ROMs are not included.

Example using PC-1245:
a. Launch the app and select PC-1245 on the home screen.
b. Tap "ROMを登録" (Register ROM). Select a compatible, lawfully obtained PC-1245 ROM in the iOS file picker. The app validates and copies it into its local library.
c. Tap "プレイ" (Play). The machine screen opens in landscape and emulation starts.
d. Switch to PRO using the RUN/PRO button. Type these lines on the on-screen keyboard, pressing ENTER after each:
10 PRINT 1+2
20 END
e. Switch to RUN, type RUN, and press ENTER. The result is 3.
f. The three-dot menu provides Run/Pause/Reset and Program Load/Save. Home supports list/tile layouts and restoring the previous machine-list position.

The attached review-sample.bas contains the same two-line BASIC program, written for this review. It can also be loaded via the three-dot menu > "プログラム" (Program) > "ロード" (Load). It contains no ROM or third-party program. It is not firmware and cannot start emulation without a compatible ROM.
