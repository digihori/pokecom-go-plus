## 英文回答の日本語確認用

App Reviewご担当者様

Pokecom GO Player（Apple ID：6826764410）、Version 0.7.0、Build 3の審査をありがとうございます。Guideline 2.1で求められた6項目について回答します。

### 1. 実機の画面収録

iOS 27.2を搭載したiPhone SE（第3世代）で収録した画面録画を添付します。本アプリはiPhone SE（第3世代）の実機で動作確認しています。

### 2. 目的と対象者

Pokecom GO Playerは、昔のプログラム可能なポケットコンピュータのオフラインエミュレータです。ポケットコンピュータの所有者・愛好家、BASICプログラミングに関心のある方を対象にしています。

画面上のキーボードとLCDを使って、自作プログラムの実行やプログラムファイルの入出力を行えます。利用者が使用権限を持つROMを用い、元の機器を持ち歩かずにiPhoneで当時のプログラミング環境を利用できる価値を提供します。

### 3. 初期設定、主要機能、サンプルファイル

ログイン、外部機器への接続、有料サービスは不要です。ただし、エミュレートする機種を動作させるには互換性のあるROMが必要です。ROMは同梱していません。

PC-1245での例：

1. アプリを起動し、ホームでPC-1245を選びます。
2. 「ROMを登録」を押し、iOSのファイル選択画面から適法に入手した対応ROMを選びます。アプリは検証してローカルライブラリへコピーします。
3. 「プレイ」を押します。機種画面が横向きで開き、エミュレーションが開始します。
4. RUN／PROボタンでPROに切り替え、次の各行を画面上のキーボードで入力します。各行の後にENTERを押します。

```basic
10 PRINT 1+2
20 END
```

5. RUNモードへ切り替え、`RUN`を入力してENTERを押すと、結果は`3`です。
6. 3点メニューではRun／Pause／Resetやプログラムのロード・セーブを利用できます。ホームはリスト／タイルと前回の機種一覧位置の復元に対応します。

添付の `review-sample.bas` は、審査用に作成した同じ2行のBASICプログラムです。3点メニュー→「プログラム」→「ロード」から読み込むこともできます。ROMや第三者のプログラムは含みません。ファームウェアではなく、これだけではエミュレーションを開始できません。

メーカーの著作権保護されたファームウェアを、許諾なく提供することはできません。添付の実機動画と説明でROMに依存する機能を確認可能か、またはメーカー製ファームウェアを再配布せずに提供すべき追加の審査用アクセス手段をご案内ください。

### 4. 外部サービス、ツール、プラットフォーム

エミュレーションは端末内で行います。開発者のサーバー、データ提供サービス、認証サービス、決済サービス、AIサービス、オンラインROM提供元には依存しません。

Apple標準のファイル選択機能を使用します。ローカルファイルはクラウドサービスなしで使えます。利用者がiOSのファイル提供元を有効にすれば、iCloud DriveやGoogle Driveも任意で選択できます。Google SDKや独自のクラウド認証・同期機能はありません。

外部キーボードやゲームコントローラも任意で、AppleのAPIを利用します。GitHubへのリンクはプロジェクト紹介・サポートのための任意のリンクで、中核機能には不要です。

すべての配信地域で機能と同梱コンテンツは共通です。地域限定のサービスやコンテンツカタログはありません。
