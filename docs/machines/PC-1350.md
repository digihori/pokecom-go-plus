# PC-1350 Machine Definition

**ステータス:** 次期実装対象・参照実装調査  
**Machine ID:** \`pc-1350\`  
**Generation:** S1（第2世代）

PC-1350は、S1系の最初の実装機種とする。25文字×4行LCDとOLD系とは異なるメモリ配置を使い、
Machine Definition、Display Snapshot、画面レイアウトが特定機種へ固定されていないかを検証する。

## 参照実装から確認した構成

| 項目 | 値 |
|---|---|
| 書込み可能範囲 | \`0x2000..0x7fff\` |
| LCD | 25文字×4行、1文字6列×8行相当 |
| LCDデータ | 20個の不連続な30byte領域、合計600byte |
| シンボル | \`0x783c\` |
| キーマトリクス | 12グループ |
| ROM形式 | Pokecom GOでは64KiBフラットイメージ |

LCDデータ領域は\`0x7000\`、\`0x7200\`、\`0x7400\`、\`0x7600\`、\`0x7800\`を基準とし、
各基準の\`+0x00\`、\`+0x40\`、\`+0x1e\`、\`+0x5e\`から30byteずつ配置される。
PGPではこの物理配置をUIへ漏らさず、600列×8行の論理表示へ変換する。

ROMの正規コンポーネント分割、実クロック、S1 BASIC格納形式、特殊文字、ROMバージョン差は
実装開始前に追加確認する。参照実装の\`CLOCK = 768\`には「違うよなぁ」という注記があり、
確定値として採用しない。
