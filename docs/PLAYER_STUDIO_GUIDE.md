# Pokecom GO Studioについて

更新日: 2026-10-15

Pokecom GO Studioは、レトロなポケットコンピュータ向けプログラムを現代のPC上で作成・実行・解析し、実機への転送まで支援するマルチプラットフォーム開発環境です。

macOS／Windows／Linuxで利用できます。Project管理、BASIC編集、外部SC61アセンブラー連携、Debuggerなどを備えています。実機への転送支援には対応形式・手順の制限があるため、配布版の説明を確認してください。

Studioで用意した、その機種に対応するBASICテキスト（.bas）やPGP Memory Dump（.dmp）をPlayerへ渡し、「プログラム」から読み込めます。ProjectそのものやWAVはPlayerへ読み込めません。

Studioの対応機種とAndroid Playerの対応機種は異なります。現在のAndroid PlayerはPC-1245とPC-1401に対応しています。ROMはどちらにも同梱していません。
