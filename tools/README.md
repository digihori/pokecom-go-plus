# 補助ツール集

Studioとは独立して使う任意のツールです。利用に必要なPython等は各自で用意してください。
StudioのUIからは呼び出しません。各フォルダーの手順を確認して実行してください。
コマンド例はリポジトリ直下を基準にしています。

## 利用者向け

| 場所 | 用途 | 必要な環境 |
| --- | --- | --- |
| [pcwav](pcwav/README.md) | BASIC／バイナリーのWAV変換、WAV復元 | Perl 5、追加CPANモジュール不要 |
| [memory](memory/README.md) | 旧Pokecom GO等の生バイナリーとDMPの相互変換、Intel HEX出力、DMP情報表示・検証 | Python 3.10以降、追加パッケージ不要 |
| [pc1360k-rom-dump](pc1360k-rom-dump/README.md) | PC-1360K専用の漢字ROM吸い出し用BASICと録音復元 | 実機、転送・保存環境。録音復元はPython 3.10以降 |

## ROM吸い出しツールの位置づけ

通常のROM吸い出しも今後の対象に含めます。現時点でここにある実機吸い出しツールは
PC-1360Kの漢字ROM専用で、通常の内蔵ROM・外部ROM・他機種向けの汎用吸い出し機能ではありません。
既存ツールの詳細な対応範囲と未検証事項は、そのREADMEを参照してください。

通常ROM向けツールを追加するときも、単独実行できる構成とし、対象機種・ROM領域・バンク、
使用RAM、実機での保存／転送手順、復元方法、サイズ等の検証、実機確認状況をセットで記載します。
BASICや機械語の吸い出し手順は機種別にし、共用可能な変換・検証処理だけを共用する方針です。
ROMデータそのものは同梱しません。

`memory`は取得済みバイト列の形式変換だけを行います。実機ROMの読出し、バンクの識別、
ROM内容の正当性確認やStudio用ROMセット（`.pgrom`）の作成は行いません。

開発者向けのソース生成スクリプトは、[scripts/](../scripts/README.md)に分離しています。
