# PC-1360K 漢字ROM吸い出し用BASIC

PC-1360K実機で漢字ROMを読み出し、`CSAVE M`で連続保存するBASICプログラム。
実機で回収できた選択値0〜3の論理256KiBを、2回に分けて吸い出す。
READ(LDPC)を使う機械語はBASICのDATA行に含まれており、別途アセンブルする必要はない。

今回ここへまとめたものは、**ドキュメントとBASICソース2本のみ**。
WAVエンコーダー／デコーダー、復元スクリプト、ROM本体、録音ファイルは同梱していない。
BASICの実機への転送と録音のデコードには、別途対応する手段が必要になる。

## ファイル

| ファイル | 対象 | 回収量 |
| --- | --- | ---: |
| [pc1360k-kanji-dump-01.bas](pc1360k-kanji-dump-01.bas) | 選択値0・1 | 64KiB × 2 |
| [pc1360k-kanji-dump-23.bas](pc1360k-kanji-dump-23.bas) | 選択値2・3 | 64KiB × 2 |

ファイル名末尾の`01`／`23`は対象の選択値を示す。バージョン番号ではない。
両プログラムの違いは、行60のブロック番号範囲だけ。
従来の解析時の名前は、それぞれ`read-all.bas`／`read-all-23.bas`だった。
ファイル名と配置を変更したが、BASICの内容は変更していない。

## 実行前に確認すること

- 対象はPC-1360K。PC-1360など別機種向けのプログラムではない。
- 以下のRAM範囲を使える構成が必要。実行すると既存内容を上書きするため、必要なデータを先に退避する。
- 録音はブロック間の無音区間を含めて継続する。録音側の無音による自動停止は使わない。
- 実機での実測は1回約65分。2本で合計約2時間10分の録音になる。時間には機器・環境による差がある。

| 使用範囲 | 用途 |
| --- | --- |
| `0xC000〜0xC11B` | DATA行から書き込む機械語 |
| `0xC200〜0xC21B` | パラメーター・比較結果等 |
| `0xC220` | 実行状態 |
| `0xCFF0〜0xCFFF` | 保存用識別ヘッダー |
| `0xD000〜0xDFFF` | 読出しデータ4096バイト |

BASICプログラム自身や必要なデータと上記範囲が重ならないことを確認する。
実行中は通常ROMバンクやFポートを機械語から切り替えず、漢字ROM選択値を`0x3600`へ書き込んで読む。
機械語から戻る際の選択値は1となる。

## 手順

1. `pc1360k-kanji-dump-01.bas`を、新しいBASICプログラムとして実機へ転送する。
2. PCなどの録音側で、実機の保存出力を録音し始める。
3. 実機で`RUN`する。
4. 読出し、同じ範囲の再読比較、`CSAVE M`を32回繰り返す。途中のENTER待ちや手動保存操作はない。
5. `DONE`が表示されたら録音を止め、選択値0・1の録音として保存する。
6. `pc1360k-kanji-dump-23.bas`へ入れ替え、同じ手順で別の録音を作る。

2本目は、実機上の行60だけを次のように変更する方法でも実行できる。

```basic
60 FOR K=&20 TO &3F
```

1本目の行60は`60 FOR K=&0 TO &1F`。
アドレスや機械語DATAなどは`&`付きの16進表記で、BASICの行番号・分岐先は10進表記としている。

## エラーと終了

4KiBごとに再読比較し、不一致数`D`が0でなければ、そのブロックを保存する前に停止する。
`ERROR BLOCK:`の番号と`D:`の値を記録し、それまでの録音も残す。
全32回を保存すると`DONE`を表示する。

プログラムは実行中のまま読出し・比較・保存を繰り返す。
今回の実機確認では、約65分ずつの両録音とも最後まで保存できた。
電源管理の未確認RAMを書き換える処理は入れていない。

## 保存データについて

各`CSAVE M`の保存範囲は`0xCFF0〜0xDFFF`、4112バイト。
先頭16バイトが識別ヘッダーで、その後ろの4096バイトが漢字ROMから読んだデータとなる。
録音や、このヘッダー付きデータをそのままStudioの漢字ROM欄へ指定することはできない。

録音を対応デコーダーで復元し、ヘッダー・再読結果・合計値・転送チェックサムを確認したうえで、
各選択値の16ブロックをアドレス順に結合すると、64KiBファイルが4つ得られる。
現段階の公開物だけで、このデコード・結合工程まで完結するわけではない。
